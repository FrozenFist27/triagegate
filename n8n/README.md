# n8n workflows

Generated by `python scripts/build_n8n_workflows.py` (stable node ids), imported with
`bash scripts/reload_workflows.sh`, verified to import into a fresh container with `scripts/verify_import.ps1`.

| File | Trigger | Does |
|---|---|---|
| `wf1_triage_intake.json` | Webhook `POST /webhook/triage-ingest` (header `X-Ingest-Token`) or read-only IMAP (disabled) | triage-api, Slack card, save Slack ref, respond |
| `wf2_slack_approval_handler.json` | Webhook `POST /webhook/slack-actions` (raw body) | decide, HubSpot search/upsert, company or ticket, record result, update card |
| `wf3_approval_expiry.json` | Schedule, every minute | expire overdue approvals, update their Slack cards |

Environment read via `$env` (set in `docker-compose.yml`, values from `.env`): `TRIAGE_API_TOKEN`, `N8N_INGEST_TOKEN`,
`SLACK_BOT_TOKEN`, `SLACK_APPROVAL_CHANNEL_ID`, `HUBSPOT_SERVICE_KEY`, optional `HUBSPOT_API_BASE`.
The only n8n credential is `TriageGate IMAP`, used by the disabled IMAP node.
